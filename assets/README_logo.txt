Place the hospital logo image files here.

Files expected:
- logo.png    -> used as site favicon and header logo (/assets/logo.png)
- og-image.jpg or og-image.png -> optional social preview image (/assets/og-image.jpg)

Recommended sizes:
- favicon: 32x32 or 48x48 (PNG)
- header logo: 72x72 (PNG) — transparent background preferred
- Open Graph image: 1200x630 (JPEG/PNG)

How to add the provided logo from the chat:
1) Download the provided logo image to your workstation.
2) Copy it into this repo under `/assets/logo.png`.

Example (on Linux):
```bash
# from your local machine where logo.png is downloaded
cp ~/Downloads/logo.png /workspaces/kmshospitals/assets/logo.png
# or if using git locally, add and commit
git add assets/logo.png
git commit -m "Add hospital logo"
```
